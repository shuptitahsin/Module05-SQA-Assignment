# Module 05 - Problem Solving with AI (Claude Code + JavaScript)

This repository contains my Module 05 JavaScript coding assignment.
The programs were developed to practice basic problem-solving using
JavaScript with AI assistance.

- JavaScript
- Node.js
- Visual Studio Code
- Claude Code
- Git
- GitHub

## Requirements / Environment

The following software is required to run the program locally:

- Visual Studio Code
- Node.js
- Git

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open the terminal.
3. Run the JavaScript file using:

node assignment5.js

## Assignment Tasks

1. Convert Celsius to Fahrenheit
2. Find the Factorial of a Number
3. Check for Palindrome
4. Sum of Array Elements
5. FizzBuzz (Basic)
